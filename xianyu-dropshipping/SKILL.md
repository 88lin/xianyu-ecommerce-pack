# 闲鱼货源与无痕代发

## R — 原文 (Reading)

> 无痕发货是电商的一种发货方式，指供应商直接将商品寄给买家时，不显示自身信息和价格，让买家以为是卖家自己发货……新手千万不要绕开货源平台下单，比如私下给商家、工厂打款等，可能会出现卷款跑路不发货的情况。
>
> — 海底桃，【五】选品、货源与发货

---

## I — 方法论骨架 (Interpretation)

无货源模式的本质是当「中间商+传话筒」，核心风险全在履约环节，规则只有三条：

1. **货源选择**：1688 为主（淘宝官方批发，无痕友好），拼多多为辅（价格常有优势但要处理痕迹）；一定要走平台下单，绝不私下打款（防卷款跑路）
2. **代发流程**：买家下单 → 确认地址 → 去货源平台拍同款填买家信息 → 拿到单号回填闲鱼发货。地址是明文可复制的，无需解密
3. **无痕三招**：1688 下单备注「无痕发货，不放卡片」；拼多多先问客服能否不放卡片/短信，不行就换一家；实在躲不掉就备好话术（"两家店都是我们的"）
4. **拼多多短信拦截**：收货手机号填自己的再转取件码（耗时）；或故意写错中间几位只保后 4 位正确（买家凭尾号取件）
5. **退货镜像**：退货也是在货源平台操作——下单退货、约上门取件、把取件码给买家；闲鱼无运费险，非质量问题运费买家出

## A1 — 应用示例 (Application Example)

### 示例 1: 标准代发一单
- **类型与来源**: 原书流程（【五】发货方法）
- **问题/输入**: 闲鱼买家拍了 39.9 元的收纳架，进货价 25 元
- **方法论的使用**: 复制买家地址 → 1688 下单同款、填买家信息、备注"无痕发货，不放卡片" → 1688 出单号后回填闲鱼点发货
- **结论**: 全程 10 分钟，赚 14.9 元差价
- **结果**: 买家收到的是无卡片包裹，感知为卖家直发

### 示例 2: 拼多多卡片躲不掉
- **类型与来源**: 原书场景（【五】无痕发货）
- **问题/输入**: 拼多多客服说卡片是店铺规定必须放
- **方法论的使用**: 换一家问；找不到就启用话术预案
- **结论**: "拼多多的店铺也是我们的，不同平台给商家的补贴不一样""走的多多物流，有运费补贴"——若卡是好评返现卡，先向拼多多要返现，再给买家返一部分
- **结果**: 痕迹被解释为多渠道经营，还能赚返现差价

## E — 可执行步骤 (Execution)

**必需输入**: 商品（已在闲鱼上架，必填）；买家收货信息（订单详情可复制）；货源链接（1688/拼多多同款）
**交付物**: 发货执行清单 + 无痕配置确认 + 异常预案

1. **货源确认**
   - 1688：找同款，确认支持一件代发、地址可填第三方
   - 拼多多：下单前问客服「能否不放卡片、不发短信」；不行就换店
   - 完成标准: 货源链接 + 无痕答复确认

2. **下单代发**
   - 复制买家明文地址 → 货源平台下单 → 1688 备注"无痕发货，不放卡片"
   - 完成标准: 货源订单生成

3. **手机号策略**（拼多多货源时）
   - 方案 A：填自己手机号，收取件码后闲鱼转给买家（慢但稳）
   - 方案 B：故意写错中间几位、保后 4 位正确，买家凭尾号取件（快）
   - 完成标准: 已选方案并知会买家取件方式

4. **单号回填**
   - 货源出单号 → 闲鱼订单点发货 → 粘贴单号
   - 完成标准: 闲鱼显示已发货，物流可追踪

5. **售后联动**（若买家退货）
   - 货源平台申请退货 → 约快递上门 → 把取件码/时间转告买家
   - 非质量问题退货：运费买家承担（详情页需已写明）；货源有运费险则赚取运费差额
   - 完成标准: 退货闭环，退款到账

6. **红线自检**
   - 绝不私下给商家/工厂转款（原书：可能卷款跑路）
   - 全部交易走平台（买家在闲鱼、卖家在货源平台）
   - 完成标准: 无任何站外资金往来

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 有现货的自营模式——直接闲鱼发货即可，无需代发流程
- 大件/物流特殊品（家具大家电）——运费与破损复杂度超出原书覆盖

### 作者在书中警告的失败模式

- 私下打款给商家 → 卷款跑路风险（原书唯一的"千万不要"级警告之一）
- 买家收到拼多多发货短信 → 暴露代拍身份 → 用手机号策略预防
- 新手囤货 → 原书立场：不要囤货

### 作者的盲点 / 时代局限

- "写错手机号中间几位"依赖快递柜/驿站凭尾号取件的普及度，部分场景需完整手机号
- 1688/拼多多规则（卡片、运费险、短信）随平台政策变动

### 容易混淆的邻近方法论

- 传统电商仓储发货（自囤自发）——本 skill 明确反对囤货
- 海外 dropshipping（Shopify+速卖通）——逻辑同源但物流周期完全不同
