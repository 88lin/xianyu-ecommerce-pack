# 闲鱼商品详情文案

## R — 原文 (Reading)

> 文案结构大致包含：标题 + 产品基本信息 + SKU/价格信息 + 物流/发货信息 + 售后信息 + 使用感受 + 卖家承诺。……注意拼凑起来之后的产品信息要跟你真正要卖的商品对得上。
>
> — 海底桃，【四】商品详情

---

## I — 方法论骨架 (Interpretation)

详情文案的任务是「替你当客服」——写得越足，静默单（不问直接拍）越多：

1. **七段结构**：标题 → 产品基本信息（型号/规格/成色）→ SKU/价格信息 → 物流/发货信息（时效/快递）→ 售后信息（退换规则，闲鱼无运费险要写明）→ 使用感受（第一人称，真实感）→ 卖家承诺（不正包退/售后响应）
2. **信息源取舍**：1688 货源详情页属性不全抄——参考闲鱼同行文案决定保留哪些；懂行客户可能问没写的参数 → 把更多参数放进客服常用回复
3. **不懂就问**：专业词汇问货源客服/京东客服（回复积极专业）/开小号装客户问闲鱼同行；客户问到不会的也走这条路
4. **AI 整合**：把产品信息+几个同行文案喂给 AI 改写成七段结构——但必须核对拼凑后的参数与实际要卖的商品一致（错参数=售后炸弹）
5. **静默单策略**：低客单品详情写足（当客服不值得）；中高客单详情打底、话术收尾

## A1 — 应用示例 (Application Example)

### 示例: 入耳式耳机详情整合
- **类型与来源**: 原书方法推演（【四】文案 + 【五】耳机配件案例）
- **输入**: 1688 货源参数表 + 3 个闲鱼同行详情
- **动作**: 按七段结构整合，参数只留同行都写的核心项（蓝牙版本/续航/防水等级），其余入客服话术库
- **产出**: 一篇静默单导向的详情 + 一份补充参数客服回复

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

- 新品上架要写详情，面对一堆货源参数不知取舍
- 链接有人看但没人拍（问题在详情不在标题）
- 想减少客服咨询量，让低客单客户直接下单（静默单）

### 语言信号 (用户的话里出现这些就应激活)

"详情页怎么写" / "文案什么结构" / "参数要不要写" / "怎么让客户不问直接拍" / "为什么有人看不下单"

### 与相邻 skill 的区分

- 没人进链接 → 是标题/主图问题（title-seo / product-images），不是文案问题
- 定价测算 → pricing-profit；询单后的聊天 → sales-service

## E — 可执行步骤 (Execution)

0. **执行前对齐**（缺任一项先向用户要，不要猜）
   - 商品实际参数（1688 链接或用户提供）
   - 客单价档位（低客单详情写足冲静默单 / 中高客单详情打底）
   - 售后规则底牌（运费谁承担、退换条件）
   - 完成标准: 三项对齐，产出物口径确定为「详情文案 + 客服回复包」

1. **收集原料**
   - 货源参数表（1688）+ 2~3 个同行详情文案
   - 完成标准: 两类原料齐备

2. **参数取舍**
   - 同行都写 → 进详情；只有货源写 → 进客服回复库
   - 完成标准: 参数两分法完成

3. **七段成文**
   - 按结构写：标题/基本信息/SKU 价格/物流售后/使用感受（第一人称）/卖家承诺
   - 判停条件: 缺任一段 → 补齐再继续
   - 完成标准: 文案可直接粘贴闲鱼

4. **一致性核对（强制）**
   - 逐项核对文案参数 vs 实货参数（型号/规格/材质/兼容性）
   - 判停条件: 发现错配 → 修正后重查
   - 完成标准: 0 错配

5. **客服回复包**
   - 未写入详情的参数 + 高频疑问（正品？全新？）写成快捷回复
   - 完成标准: 详情+回复包双交付

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 询单转化问题（有人问不买）→ 用 `xianyu-sales-service` 话术
- 标题/主图问题（没人进链接）→ 用 title-seo / product-images

### 作者在书中警告的失败模式

- 拼凑文案参数与实货不符 → 售后纠纷
- 参数全抄货源页 → 冗长且暴露无货源感
- 承诺写过头（假一赔十类）→ 售后被动

### 作者的盲点 / 时代局限

- 七段结构偏实体电商；虚拟服务类（技能接单）详情需改造（案例/交付物/流程替代参数）
- "使用感受"为无货源卖家人设文，平台对虚假宣传的尺度可能收紧

### 容易混淆的邻近方法论

- AIDA 销售文案模型——通用转化逻辑，本 skill 是闲鱼详情页专用结构
- 详情页 UI 设计（图文排版）——本 skill 只管文字内容
