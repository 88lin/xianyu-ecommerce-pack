# 闲鱼商品图片规划与制作

## R — 原文 (Reading)

> 闲鱼商品的主图和标题就像小红书笔记的封面和标题，很大程度上决定了你的链接的生死。……链接的图最好都是实拍图，而不是像电商平台或者小红书上精修过的图。
>
> — 海底桃，【三】商品图片

---

## I — 方法论骨架 (Interpretation)

闲鱼图片的铁律：**实拍感 > 精修感**。用户来闲鱼是"捡闲置"心智，太精美反而像假货。方法四层：

1. **9 张图规划**：主图（封面，1:1 或 3:4，定生死）+ 多角度展示图 + 使用场景图 + 配件图 + 包装图 + 现货图 + 价格对比图（淘宝/京东价格截图做锚点，突出闲鱼价优势）
2. **合规图源**（无货源不买样品）：同行链接/同行评价区、其他电商平台评价区取图；两条红线——不照搬闲鱼同行的图（会被投诉下架）、不用官方主图（品牌方一投诉一个准）
3. **修图流程**：裁 3:4、产品主体放中间 1:1 区域 → 调亮度/对比度 → 加文字（产品名+卖点+优势）；工具：电脑美图设计室、手机美图秀秀，免费版够用；不加花哨贴纸、主图只放要卖的产品（放过显示器就别带键盘机箱）
4. **去重 + 标签**：去重三招（调亮度对比度/加文字贴纸/叠 1% 透明度无关图层）；每图 ≤10 个标签，标签词从抖音指数搜产品词取关联词（小米/米家/扫地机/扫拖一体…），标签不进搜索结果但显示在详情页，排整齐

## A1 — 应用示例 (Application Example)

### 示例: 米家扫地机器人主图
- **类型与来源**: 原书示例（【三】制作图片）
- **输入**: 从电商平台评价区取的扫地机器人实拍图
- **动作**: 裁 3:4，主体居中 → 提亮 → 加"米家扫地机器人 全自动扫拖一体"文字
- **产出**: 一张实拍感主图 + 标签：小米、米家、扫地机器人、扫拖一体、性价比

## E — 可执行步骤 (Execution)

0. **执行前对齐**（缺任一项先向用户要，不要猜）
   - 用户是否有样品/实拍条件（有则优先自拍，无则走取图流程）
   - 商品品类（决定场景图怎么拍）
   - 是否存在品牌方投诉风险（品牌数码>白牌日用品）
   - 完成标准: 三项对齐，产出物口径确定为「9 图规划 + 逐张内容/来源/文字建议 + 标签词表」

1. **9 张图规划**
   - 逐张确定类型与内容；主图先定（产品名+核心卖点文字）
   - 完成标准: 9 个格子都有明确内容

2. **图源合规检查**
   - 闲鱼同行图 → 只参考构图，不直接搬；官方主图 → 禁用
   - 优先级：自拍 > 评价区实拍 > 其他平台买家秀
   - 完成标准: 每张图标注来源且通过红线检查

3. **主图制作指导**
   - 3:4 裁剪、主体居中占画面大部分、提亮、加 1~2 行卖点文字、去花哨贴纸
   - 完成标准: 输出给用户的操作步骤可直接照做（含工具名）

4. **去重处理**
   - 搬运图必做：亮度/对比度微调 + 文字层 + 1% 透明度叠层（可多层）
   - 完成标准: 每张非原创图至少两重去重

5. **标签选词**
   - 抖音指数搜产品词 → 取高关联词 ≤10 个/图
   - 完成标准: 标签词表 + 提醒排版整齐（显示在详情页）

6. **A/B 测试衔接**
   - 主图与标题搭配测试，3~5 天看点击率，不行换主图重发
   - 完成标准: 告知测试节奏

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户能自己实拍且有样品——直接自拍就是最好的图，跳过取图流程
- 小红书/抖音带货封面——精修+情绪钩子逻辑，与闲鱼相反

### 作者在书中警告的失败模式

- 照搬闲鱼同行图 → 投诉下架
- 用品牌官方主图 → 品牌方投诉，"一投诉一个准"
- AI 生成精美电商图 → 违背实拍感铁律，转化反而差
- 主图塞进无关产品 → 客户来问不卖的东西
- 贴纸堆砌 → 主体不突出

### 作者的盲点 / 时代局限

- 评价区取图本质是搬运他人图片，版权风险原书未讨论（平台投诉之外的法律风险）
- 平台图片查重算法会进化，去重技巧时效性强

### 容易混淆的邻近方法论

- 电商精修主图方法论（白底图/场景精修）——闲鱼语境反而不利
- 小红书封面方法论——信息流点击逻辑，可参考"标题+封面决定生死"的类比，不可照搬风格
