# 闲鱼定价与利润测算

## R — 原文 (Reading)

> 毛利 = 售价 − 进货成本；净利 = 毛利 − 手续费（0.6%）− 补单成本……这种品看起来也有单量，但利润很薄，就不能只看"卖了多少"，还要看值不值得继续推。
>
> — 海底桃，【四】商品详情 / 【工具】盈亏表

---

## I — 方法论骨架 (Interpretation)

定价不是拍脑袋，是「利润倒推 + 转化技巧」双轨：

1. **真实净利公式**：净利 = 售价 − 进货价 − 平台手续费（成交额×0.6%，2024.09 起）− 补单成本 − 退货损耗。只看毛利会自欺，原书案例：毛利看着可观、扣完只剩 4.62% 真实毛利率的品不值得推
2. **定价策略**：参考同行价格带，新手先落在同行主流价格区间内（不最低也不最高）
3. **低价引流 SKU**：用一个低价配件 SKU 拉点击和转化（如卖耳机配 9.9 元耳机套），核心 SKU 正常价；红线是恶意低价（明显低于市场价 15~20% 以上易被平台判低价引流违规）
4. **支付摩擦优化**：闲鱼币大额抵扣（买家省、卖家曝光加权）、花呗支付（缓解买家资金压力，实体电商回款后再还进货款 = 近零成本启动）
5. **发布城市**：同城流量入口——按常识判断目标城市，或用抖音指数查该品的城市偏好分布选高热度城市发布

## A1 — 应用示例 (Application Example)

### 示例 1: 薄利品识别
- **类型与来源**: 原书示例（【工具】SKU 盈亏表）
- **问题/输入**: 某品每天有单量，月底却没利润
- **方法论的使用**: 出单表按 SKU 算：售价 − 进货 − 0.6% 手续费 − 分摊补单成本
- **结论**: 真实毛利率只有 4.62%——单量好看但利润薄，不值得继续推
- **结果**: 停掉该品，把补单预算挪给高毛利品

### 示例 2: 低价引流 SKU
- **类型与来源**: 原书方法（【四】低价引流）
- **问题/输入**: 主商品 199 元点击率低
- **方法论的使用**: 加一个 9.9 元配件 SKU（如耳机套/贴膜），SKU 图排第一拉点击
- **结论**: 用户因低价点进来，看到主商品后部分转化
- **结果**: 点击率上升（原书未给具体数据）；注意缺货 SKU 会被判定低价引流

## E — 可执行步骤 (Execution)

**必需输入**: 进货成本（1688/拼多多到手价，必填）；同行价格带（需现场查）；预期补单量（可选，默认 0）
**交付物**: 建议售价区间 + 单笔净利测算表 + SKU/抵扣/城市配置建议

1. **采集价格带**
   - 闲鱼搜产品词，记录前 10 个同规格链接的价格（排除全新转卖异常价）
   - 完成标准: 有最低/主流/最高三档价格

2. **成本核算**
   - 进货价 + 运费（若买家包邮则计入成本）+ 预估退货率（保守 5%）
   - 完成标准: 单件完全成本明确

3. **净利测算**
   - 净利 = 售价 − 完全成本 − 售价×0.6% − 单均补单成本
   - 真实毛利率 = 净利/售价；参考阈值：低于 10% 的品要慎重投入运营
   - 完成标准: 主流价格带下每个价格档的净利与毛利率

4. **定售价与 SKU 结构**
   - 主 SKU 落主流价格带；可加低价引流 SKU（真实存在的配件，非虚构）
   - 判停条件: 低价 SKU 必须真实可发货，否则删掉（防恶意低价判定）
   - 完成标准: 售价 + SKU 结构确定

5. **支付与城市配置**
   - 开闲鱼币大额抵扣；实体高客单可开花呗分期
   - 发布城市：常识判断目标城市（如潮玩→一二线年轻城市），或抖音指数查城市偏好选 Top 城市
   - 完成标准: 三项配置有明确建议

6. **回款周期提醒**（实体电商）
   - 货款垫付 → 买家确认收货回款 → 还花呗/信用卡；窗口期一般 3~10 天
   - 完成标准: 告知用户资金占用周期与上限

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 拍卖/议价玩法（闲鱼少数类目）——原书未覆盖
- 其他平台费率结构（淘宝天猫扣点不同）——只套闲鱼 0.6% 规则

### 作者在书中警告的失败模式

- 只看毛利不算净利 → 补单成本和手续费吃掉利润
- 恶意低价引流（虚构缺货 SKU/明显低于市场价 15~20%）→ 平台判违规
- 定价远低于同行 → 买家怀疑假货（"这么便宜是不是有问题"）

### 作者的盲点 / 时代局限

- 0.6% 费率为 2024.09 后规则，后续可能调整
- "低于市场价 15~20% 判违规"为经验阈值，平台无公开标准

### 容易混淆的邻近方法论

- 成本加成定价法（cost-plus）——本方法以同行价格带为锚，成本只做下限校验
- 撇脂定价（高价撇脂）——闲鱼用户价格敏感，不适用
