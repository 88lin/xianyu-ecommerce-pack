# 闲鱼运营与冷启动推流

## R — 原文 (Reading)

> 新发布的链接在发布并通过审核后的几小时内会有推流……把一条链接的文案、图片稍微改改后重新发布，也会被平台视为新链接。这是一种给旧链接重新推流的方法。……过度补单会造成限流。
>
> — 海底桃，【六】日常运营与快速出单技巧

---

## I — 方法论骨架 (Interpretation)

运营 = 持续制造「平台愿意推的新鲜信号」+ 用补单伪造「用户喜欢的成交信号」：

1. **每日上品**：至少每 2 天上新 1 条（每日更佳）；上品要垂展（围绕店铺人群）；新链接过审后有几小时推流窗口
2. **旧链接翻新**：文案图片稍改后重发 = 平台视为新链接 = 再吃一次推流
3. **鱼小铺配置**：合集（同类打包，≤2 个）+ 置顶（爆品/主打品，≤2 条）
4. **免费四件套**：每日签到（新号养活跃度）、每日擦亮（刷新上架时间，泛流量）、任务送曝光（加到主链接上）、0 点抢闲鱼币推广额度
5. **付费两件套**：闲鱼币买曝光（急速卖，每日限量）；超级擦亮（精准流量，付费）
6. **补单体系**（灰色，需节制）：小黄鱼（评论"好看1"换互访成交）→ 群补（圈内互刷，差价私下退回）→ 全价精补（一对一全价成交，成本=手续费）；规划节奏 D1×3/D2×5/D3×7；间隔几小时发货、不早于次日早上确认收货；「有效单」= 系统认可的真实出单，过度补单直接限流

## A1 — 应用示例 (Application Example)

### 示例 1: 新链接三日冷启动
- **类型与来源**: 原书补单规划（【六】）
- **问题/输入**: 新品上架，零想要零销量，没信任度
- **方法论的使用**: D1：上架 3h 后找 3 人各补一单；D2：选前一天曝光最高链接，5 个新人各补一单；D3：7 人补曝光最高链接
- **结论**: 三天 15 单初始数据，链接带上想要数/销量/评论
- **结果**: 平台判为「可出单的好链接」加推流；真实询单开始进来

### 示例 2: 补单翻车（限流）
- **类型与来源**: 原书反例（【六】注意事项）
- **问题/输入**: 某品全闲鱼一天才出 10 单，卖家一上午补了 20 单
- **方法论的使用**: 反面教材——补单量远超品类大盘，系统识别异常
- **结论**: 商品限流
- **结果**: 教训：每天补单数要按品类在全平台的出单量定合理值，少量多次

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 新链接上架后没动静，想冷启动
2. 想要一份每天必做的运营清单
3. 曝光掉了，想救回流量
4. 听说补单，想知道怎么做、风险多大

### 语言信号

- "链接没曝光" / "怎么冷启动" / "每天要做什么运营"
- "补单" / "小黄鱼" / "刷单安全吗" / "擦亮" / "想要数上不去"
- "no exposure" / "cold start my listing"

### 与相邻 skill 的区别

- 与 `xianyu-title-seo`：那是静态优化（写一次），本 skill 是动态动作（每天做）
- 与 `xianyu-order-dashboard`：补单成本要记录进出单表，但规划在本 skill

## E — 可执行步骤 (Execution)

**必需输入**: 店铺现状（新号/老号，链接数，曝光水平）；目标（冷启动单链接/全店拉曝光）；风险偏好（是否接受灰色操作）
**交付物**: 每日运营清单（免费动作）+ 可选的补单规划（含风险告知）

1. **搭每日骨架（所有人必做，零风险）**
   - 签到；擦亮全部商品；任务领曝光投给主链接；有鱼小铺则检查合集/置顶
   - 完成标准: 清单可勾选执行，约 10 分钟/天

2. **上品节奏**
   - 每 1~2 天上 1 条新链接（同品类垂展）；旧链接改文案+图后重发吃新链接推流
   - 完成标准: 上品日历确定

3. **曝光诊断**（有问题时）
   - 曝光高想要少 → 换主图/改详情（title-seo/product-images 接管）
   - 曝光低 → 检查是否屏蔽期（用小号搜索验证），或考虑付费流量
   - 完成标准: 给出病因判断与对应动作

4. **付费流量配置（可选）**
   - 闲鱼币推广：每天 0 点抢限量曝光；超级擦亮：只投验证过能转化的链接
   - 完成标准: 预算与投放对象明确

5. **补单规划（可选，必须先做风险告知）**
   - ⚠️ 明确告知：补单是灰色操作，过度补单会限流甚至封号；细节平台敏感，原书刻意略写，需自行搜索最新方法
   - 节奏参考：D1×3 / D2×5 / D3×7，选前一天曝光最高链接；前期小黄鱼+群补冷启动，后期全价精补
   - 执行细节：间隔几小时再发货；不早于次日早上确认收货；低客单备注同城自提免邮、中高客单买虚拟单号
   - 每日补单量 ≤ 该品全闲鱼日出单量的一小部分；少量多次
   - 判停条件: 用户不接受风险 → 只输出步骤 1~4
   - 完成标准: 规划含节奏/方式/止损线，且风险声明已签署（对话确认）

6. **有效单监控**
   - 卖家侧卖出数 − 买家侧可见卖出数 = 无效单数；无效单占比升高 → 立刻降补单量
   - 完成标准: 告知用户监控口径，联动 order-dashboard 记录

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 链接本身有硬伤（标题无搜索词/主图差）→ 先修链接再谈推流（原书：补单救不了坏选品）
- 需要立刻见效的大促备战 → 闲鱼无直通车类付费加速通道，本方法以天为单位

### 作者在书中警告的失败模式

- 过度补单（案例：大盘 10 单/天，自己一早补 20 单）→ 限流
- 集中时间补一堆 → 少量多次
- 只补单不看曝光选链接 → 补错对象浪费钱
- 新手研究超级擦亮等付费工具 → 原书直言没必要，先用免费+补单

### 作者的盲点 / 时代局限

- 补单细节因平台风控刻意语焉不详，方法时效性最强、最容易过期的部分
- 小黄鱼/群补依赖社群资源，新手冷获取渠道未展开
- 补单的法律/平台规则风险仅以"限流"带过，实际可能更重

### 容易混淆的邻近方法论

- 淘宝直通车/引力魔方——付费投流逻辑，闲鱼没有对应物
- 内容种草（发笔记带货）——原书提到带货笔记但未展开方法
