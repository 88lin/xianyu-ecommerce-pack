# 闲鱼选品策略

## R — 原文 (Reading)

> 选品是 1，运营技巧是后面的 0。运营技巧是锦上添花，好的选品稍微运营就能出单，坏的选品怎么运营都不出单。
>
> — 海底桃，【五】选品、货源与发货

---

## I — 方法论骨架 (Interpretation)

选品质量决定运营天花板，方法是一套「先抄后测再放大」的漏斗：

1. **画像锚定**：闲鱼主力是 Z 世代（约 65%，潮玩/动漫）、女性（约 60%，母婴/家居）、学生职场新人（约 30%，教材/数码）+ 自由职业者接单——选品围绕这四类人的需求「垂展」（垂直+稍发散）
2. **参考同行**：搜商品找「想要数/已售」高的链接 → 点进主页找等级高的鱼小铺 → 抄专业同行的选品组合；避开接近完全竞争的品
3. **爆品雷达**：常年爆品（常年有人买的刚需品）+ 应季爆品（节假日/季节前提前 1~2 个月布局）
4. **测品漏斗**：选品后不是直接囤货，而是上架观察——曝光多但没人要→换标题主图再测；曝光少→放弃
5. **避坑清单**：不碰法律风险品（假货/盗版）、极低价品（利润撑不起运营）、巨头直接竞争品

## A1 — 应用示例 (Application Example)

### 示例 1: 跟随同行选品
- **类型与来源**: 原书示例（【五】参考同行）
- **问题/输入**: 想卖米家扫地机器人，不知道还能配什么品
- **方法论的使用**: 搜索"米家扫地机器人"→ 找到等级高的专业卖家鱼小铺 → 看其主页在卖什么
- **结论**: 同类目米家生态产品（扫地机配件、清洁耗材等）都是可跟的选品
- **结果**: 店铺围绕同一人群垂展，可信度更高

### 示例 2: 测品淘汰
- **类型与来源**: 原书原则（【五】测品）
- **问题/输入**: 上了新链接，几天了没人买
- **方法论的使用**: 先看曝光——曝光高想要少 = 详情/价格问题；曝光低 = 标题/链接权重问题
- **结论**: 曝光低的品直接放弃换下一个，不恋战
- **结果**: 把时间留给能出单的品（原书："坏的选品怎么运营都不出单"）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 准备开闲鱼店，不知道卖什么
2. 在某几个品类之间纠结
3. 看到别人卖某品火了，想判断能不能跟
4. 新品上了几天没动静，决定坚持还是放弃

### 语言信号

- "闲鱼卖什么赚钱" / "帮我选个品" / "这个类目还能做吗"
- "测品" / "想要数" / "爆品" / "应季"
- "what should I sell on Xianyu"

### 与相邻 skill 的区别

- 与 `xianyu-dropshipping`: 本 skill 决定「卖什么」，dropshipping 解决「从哪进、怎么发」
- 与 `xianyu-title-seo`: 选品是 1，标题运营是 0——先过本 skill 再优化链接

## E — 可执行步骤 (Execution)

**必需输入**: 可投入时间/资金（必填）；熟悉的人群或领域（可选）；所在季节/临近节假日（可选）
**交付物**: 候选选品清单（含理由）+ 测品执行方案 + 放弃标准

1. **画像匹配**
   - 对照四类人群（Z世代/女性/学生职场新人/自由职业者），列出用户熟悉人群的需求品
   - 没有特别熟悉的群体 → 什么赚钱卖什么，不懂现学（原书允许）
   - 完成标准: ≥5 个候选品

2. **同行验证**
   - 每个候选品在闲鱼搜索，记录头部链接的想要数/已售数
   - 点开主页确认是否专业卖家（等级高的鱼小铺）；避开接近完全竞争的品
   - 完成标准: 每品有 ≥3 个数据点，筛掉无同行做或完全饱和的

3. **爆品扫描**
   - 闲鱼热搜板块/淘宝天猫销量榜/抖音指数，交叉确认需求热度
   - 常年爆品优先（稳定），应季爆品提前 1~2 个月布局
   - 完成标准: 候选清单标注「常年/应季/趋势」类型

4. **测品漏斗设计**
   - 建议测试期与判断标准（参考原书节奏：上架后观察曝光与想要数；曝光多想要少→改标题主图重测一轮；曝光少→放弃）
   - 完成标准: 写清每个品的「继续/换图重测/放弃」触发条件

5. **避坑自检**
   - 有版权的虚拟资料 → 直接排除（原书【五】避坑警告：有人"钓鱼执法"专告侵权索赔，有公司专门干这个）
   - 客单价过低 → 利润撑不起补单成本 → 排除
   - 顺丰包邮/易碎/售后重 → 新手慎入
   - 完成标准: 清单上每个品通过全部检查

6. **虚拟品分支**（如适用）
   - 虚拟资料：几十元买断转卖，注意版权钓鱼风险；AI 服务：技能变现无库存
   - 完成标准: 若走虚拟路线，给出对应货源与风险提示

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 已经有稳定出单的爆品要放量 → 用 `xianyu-growth-ops`（补单、合集置顶）
- 淘宝/拼多多等货架平台选品：那里的竞争逻辑（销量权重、付费投流）与闲鱼不同

### 作者在书中警告的失败模式

- 上来就囤货 → 原书立场：不要囤货，一件代发
- 跟风应季品太晚（应季当口才上）→ 提前 1~2 个月
- 选品选得差还想靠运营救 → "怎么运营都不出单"

### 作者的盲点 / 时代局限

- 用户画像数据（65%/60%）无出处，为约数；平台结构会漂移
- "抄同行"未讨论同质化内卷的时点问题——大家都抄时利润已薄

### 容易混淆的邻近方法论

- 蓝海选品法（找无人竞争品）——原书反其道：找被验证有需求的品，避开的是「完全竞争」不是「有竞争」
- 兴趣电商选品（靠内容种草）——闲鱼是搜索电商，逻辑不同
