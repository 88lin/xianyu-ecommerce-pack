# 闲鱼销售话术与售后

## R — 原文 (Reading)

> 对于中高客单，静默单会逐渐减少……使用销售话术可以显著提高中高客单的转化率。……不要主动回复，要让对面给联系方式。因为这在闲鱼上属于「站外引流」，可能会导致账号被禁言。
>
> — 海底桃，【七】销售话术与售后

---

## I — 方法论骨架 (Interpretation)

话术的本质是「降低决策摩擦 + 管理信任」，售后是「用信息差把危机做成差价」：

1. **先分单型**：低客单→详情写足出静默单（当客服不值得）；中高客单→靠话术转化询单
2. **话术五板斧**：开场（能拍就有货+发货时效）→ 信任（全新未拆封/不正包退）→ 价格（完成销售指标低价跑量）→ 平台疑虑（共情+好评背书+关店承诺）→ 催单（库存不多/活动价到期/释放订单）
3. **售后三件套**：货源短信/卡片→「两家店都是我们的，一个仓库发货」；好评返现卡→先向货源要返现再分客户，赚差价；小瑕疵→先向货源要红包再赔客户，赚差价
4. **退货处理**：闲鱼无运费险——非质量问题买家承担运费（详情页写明）；货源有运费险则退货反而赚运费
5. **两条红线**：站外引流（禁言风险，别主动给联系方式，有同行设套）；没备货的其他品需求一律说没有（防止被白嫖时间）

## A1 — 应用示例 (Application Example)

### 示例 1: 正品质询
- **类型与来源**: 原书话术（【七】正品）
- **问题/输入**: 买家问"是正品吗？不正包退吗？"
- **方法论的使用**: 两段式——先给确定性（全新未拆封官方正品），再给兜底承诺（不正退款+货不退回）
- **结论**: "是的，全新未拆封官方正品，宝子放心哈。如果产品不是正品，钱退给您，产品我也不要了。"
- **结果**: 承诺成本为零（正品前提成立），信任拉满

### 示例 2: 拼多多卡片危机
- **类型与来源**: 原书场景（【七】售后-货源短信）
- **问题/输入**: 买家收货发现内附拼多多好评返现卡，质问"你是在拼多多买的吧？"
- **方法论的使用**: 统一口径「多平台多店铺」+ 顺势引导好评
- **结论**: "我们在闲鱼和拼多多都有店铺，是一个仓库发货的哈，质量您放心。满意的话给个好评，我给您返现。"——然后向拼多多要返现，分一部分给买家
- **结果**: 危机化解 + 赚返现差价

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 买家来咨询，不知道怎么回转化率高
2. 买家砍价/要求包邮，怎么不伤和气地守价
3. 买家拍下不付款/犹豫，要催单
4. 收到货出问题（瑕疵/短信/卡片/退货），要话术和流程
5. 买家要加微信/问有没有别的品——红线判断

### 语言信号

- "买家问我是不是正品怎么回" / "客户嫌贵" / "怎么催单"
- "收到货发现有拼多多的卡" / "买家要退货" / "有人要加我微信"
- "buyer asking" / "how to reply"

### 与相邻 skill 的区别

- 与 `xianyu-listing-copy`: 静默单的转化靠详情文案；询单的转化靠本 skill
- 与 `xianyu-order-dashboard`: 本 skill 给话术与判断；订单状态追踪归 dashboard

## E — 可执行步骤 (Execution)

**必需输入**: 买家消息原文/场景描述（必填）；商品客单价与利润空间（影响让步幅度）；是否有现货（影响时效承诺）
**交付物**: 可直接发送的回复文案（1~2 版）+ 后续动作清单

1. **识别问题类型**
   - 开场/正品/全新/货源价格/商品信息/选择困难/平台信任/操作不熟/自提/催单/砍价/其他平台/售后——对照原书 13 类
   - 完成标准: 类型确认，判断低客单（简短回）或中高客单（话术回）

2. **生成回复**（核心话术对照表）
   - 开场: "亲，在的。能拍就是有货，拍下最迟 48 小时发走"
   - 正品: "全新未拆封官方正品" / "不是正品钱退您，产品我也不要了"
   - 为什么便宜: "完成销售指标，低价跑量，放心"
   - 不信任闲鱼: 共情（"我一开始也不信任"）+ 好评无一差评 + "有假货你投诉到它关店"
   - 不熟操作: 引导"拍下不付款，我改好价你再付"
   - 想自提: "工厂直发没法自提，包邮到家三天左右到"
   - 催单: "库存不多了" / "活动价马上恢复原价" / "再不付款只能释放订单给别人"
   - 别的平台: "已暂停 XX 平台运营，那边成本高；闲鱼省成本让利客户"
   - 完成标准: 回复文案给出，语气与原书一致（亲切但不过度承诺）

3. **砍价应对**
   - 小刀（<10%）: 利润空间内可让，让价要换取即时成交（"现在拍就这个价"）
   - 大刀: 守价——"这个价已经是渠道底价了，再低要亏本"，可送小赠品替代降价
   - 完成标准: 让步幅度与利润测算一致（联动 pricing-profit）

4. **售后分流**
   - 货源短信/卡片 → 统一口径话术 + 向货源要返现分客户
   - 小瑕疵 → 先向货源要红包 → 再给客户红包+真诚道歉，赚差价
   - 退货 → 货源平台下单退货、约快递上门、给取件码；非质量问题要求买家承担运费
   - 完成标准: 每种售后有话术+动作两件套

5. **红线自检（每次必过）**
   - 任何场景不主动留联系方式/引导微信交易（对方给了也不接，交易必须走闲鱼）
   - 没备货的品类需求 → "没有哈，目前只做这类"
   - 完成标准: 回复中无站外引流内容、无虚构库存承诺

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 商品转化率低但没人来问 → 问题在标题/主图/详情，不在话术（用 title-seo / listing-copy）
- 纠纷已升级到平台介入/投诉 → 按平台流程处理，话术失效

### 作者在书中警告的失败模式

- 主动发联系方式 → 站外引流禁言（有同行故意设套诱导）
- 现场给客户找没准备的货 → 客户不下单白忙一场（"血淋淋的教训"）
- 详情里写"假一赔十"之类超范围承诺 → 售后被动

### 作者的盲点 / 时代局限

- 话术默认卖家供货稳定；若货源涨价/断货，时效承诺会违约
- "赚返现差价"类操作依赖拼多多商家配合度，不保证每次成立

### 容易混淆的邻近方法论

- 通用销售技巧（SPIN/FAB）——原书话术更短平快，适配二手平台轻信任场景
- 客服 SOP——本 skill 含"话术+动作"双层，不纯是回复模板
